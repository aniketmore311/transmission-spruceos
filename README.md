## What this is

[SpruceOS](https://github.com/spruceUI) is a custom firmware for a family of retro
handhelds. This project gives you a BitTorrent client on the device, with no
compilation required on your part and **no libraries to install**:

1. **A reproducible cross-build** of the official
   [Transmission](https://transmissionbt.com/) source into a **statically linked
   ARM64 `transmission-daemon`** (the whole thing is one self-contained file).
2. **A SpruceOS app** that starts/stops the daemon and shows its log location,
   using SpruceOS's standard PyUI menu system for a controller-friendly UI.

Everything the app owns lives in its own folder on the SD card; the only path
outside it is the download folder.

## Features

- Static **aarch64** daemon built from the official release — zero runtime deps.
- Includes the full Transmission **web UI**.
- SpruceOS app menu: **Start**, **Stop**, **Log file location**.
- The daemon keeps running after you leave the app; only **Stop** ends it.
- Downloads land in the device's media folder (`/mnt/SDCARD/Roms/MEDIA`), so
  finished videos show up in your media player.

## Requirements

- **Docker**, `curl`, `python3` (to build)
- A **TrimUI Smart Pro** or **Smart Pro S** running **SpruceOS** (to run)

## Build

```sh
./build.sh                  # latest official Transmission release
./build.sh --version 4.1.3  # pin a specific release
```

Artifacts are written to `output/`:

| Path | Description |
|------|-------------|
| `output/transmission-daemon` | static aarch64 ELF |
| `output/web/` | web UI assets (served by the daemon) |
| `output/manifest.txt` | version + SHA-256 checksums |

Then assemble the app directory (adds the binary, web assets and icon):

```sh
./build-app.sh
```

## Install

Copy the assembled `Transmission/` folder onto the device:

```sh
scp -r Transmission/ <user>@<device-ip>:/mnt/SDCARD/App/Transmission/
```

Open **Apps → Transmission** on the device and press **Start Transmission**.
The web UI is then available at `http://<device-ip>:9091/transmission/web/`.

| | |
|---|---|
| **Default username** | `spruce` |
| **Default password** | `happygaming` |

Change them in `settings.json` or through the web UI after first launch.

## Paths on the device

| Item | Path |
|------|------|
| App / config dir | `/mnt/SDCARD/App/Transmission/` |
| Log | `/mnt/SDCARD/App/Transmission/transmission.log` |
| Downloads | `/mnt/SDCARD/Roms/MEDIA/` |
| Incomplete downloads | `/mnt/SDCARD/Roms/MEDIA/.incomplete/` |

On first launch the app creates the download folders and seeds `settings.json`
from `settings.json.default`; your `settings.json` is never overwritten.

## How it works

- `build.sh` builds a Docker image containing a pinned
  [musl.cc](https://musl.cc) `aarch64-linux-musl` cross toolchain plus statically
  built **OpenSSL** and **libcurl** — the only external dependencies Transmission
  needs. Its remaining dependencies (libevent, libdeflate, dht, libutp, libb64,
  libpsl, libnatpmp, miniupnpc) are bundled inside the Transmission source tree.
- Transmission is cross-compiled and linked as a fully static (`static-pie`)
  binary, with the web UI assets installed next to it.
- The SpruceOS app is POSIX shell plus a tiny Python menu generator, driving the
  standard PyUI realtime interface (`helperFunctions.sh`).
- Every download/version is pinned and checksum-verified via
  [`versions.env`](versions.env).

## Repository layout

```
build.sh                 # build the static daemon (Docker)
build-app.sh             # assemble the device app directory
Dockerfile               # cross-build environment
versions.env             # pinned versions + SHA-256 checksums
cmake/                   # CMake cross toolchain file
scripts/                 # toolchain / deps / transmission / collect steps
assets/                  # app icon (SVG source)
Transmission/            # the SpruceOS app (source)
  config.json            #   app manifest
  icon.png               #   app icon
  launch.sh              #   entry point
  lib/                   #   shell + Python helpers
  settings.json.default  #   default Transmission config
output/                  # generated by ./build.sh (git-ignored)
```
